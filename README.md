## 🏗️ Featured Project

### 🥛 Smart Dairy Milk Silo — End-to-End Data Engineering

An end-to-end pipeline that processes milk silo sensor data from ingestion to analytics-ready storage.

- 📥 Ingest sensor data using Python and Azure Event Hubs.
- ☁️ Store JSON data in Azure Blob Storage.
- ⚙️ Orchestrate workflows with Azure Data Factory.
- 🧹 Validate, transform, and separate valid and rejected records.
- 🥉 Implement Bronze, Silver, and Gold data processing layers.
- 🗄️ Load processed data into Azure SQL.
- ⏱️ Use watermark-based incremental processing.

**Tech Stack:** Python | Azure Event Hubs | Azure Blob Storage | Azure Data Factory | Azure SQL
