## 🏗️ Featured Project

### 🥛 Smart Dairy Milk Silo — End-to-End Data Engineering Pipeline

An end-to-end data engineering project designed to ingest milk silo sensor data, validate and transform records, handle rejected data, and load processed data into Azure SQL for analytics.

**Key components:**
- 📥 Ingest streaming-style sensor data using Python and Azure Event Hubs.
- ☁️ Store incoming JSON data in Azure Blob Storage.
- 🔄 Orchestrate pipeline execution with Azure Data Factory.
- 🧹 Transform and validate records using Azure Data Factory Mapping Data Flows.
- 🗂️ Separate valid records from rejected records.
- 🥇 Organize data into Bronze, Silver, and Gold processing layers.
- 🗄️ Load processed records into Azure SQL.
- ⏱️ Implement watermark-based incremental processing.
- 📊 Prepare structured data for downstream analytics.

**Technologies:** Python | Azure Event Hubs | Azure Blob Storage | Azure Data Factory | Azure SQL
