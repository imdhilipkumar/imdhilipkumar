<h3>🏗️ Featured Project</h3>

<h4>🥛 Smart Dairy Milk Silo — End-to-End Data Engineering Pipeline</h4>

<p>
  An end-to-end data engineering project that ingests milk silo sensor data,
  validates and transforms records, handles rejected data, and loads processed
  data into Azure SQL for analytics.
</p>

- 📥 **Ingestion:** Python and Azure Event Hubs
- ☁️ **Storage:** Azure Blob Storage
- ⚙️ **Orchestration:** Azure Data Factory
- 🧹 **Transformation:** Mapping Data Flows and data quality validation
- 🥉 **Architecture:** Bronze, Silver, and Gold processing layers
- 🗄️ **Destination:** Azure SQL
- ⏱️ **Incremental Processing:** Watermark-based loading

<p>
  <strong>Tech Stack:</strong> Python | Azure Event Hubs | Azure Blob Storage |
  Azure Data Factory | Azure SQL
